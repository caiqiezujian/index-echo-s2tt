# 首版交付与验收边界

日期：2026-10-09。目标平台：AutoDL 单张 RTX 5090 32GB。由用户在服务器安装并执行真实验收。

## 已实现的软件

- 有状态因果 FIR 重采样、PCM16LE/通道/序号校验、不可变快照和独立 received/used/evicted 光标。
- 完整 S2TT 包 SHA256 校验、2B/9B 独立 connector 严格加载、BF16 CUDA 设备层与内存音频编码。
- 方向中立的三行解析、非法/超范围时间戳、生成截断、原始输出和结束原因记录。
- SessionCore、冻结历史/术语、任务代次、LA2/边界提交、显式 Correction、取消和 End 排空。
- 一次生成与持续收音解耦、单副本/单会话准入、有限缓存、合并待执行请求、显式错误/断连不可恢复。
- 版本化 WebSocket、浏览器 AudioWorklet 麦克风、原子提交/草稿显示、模拟模式标识。
- computation-unaware 与1×时钟因果回放、完整/短前缀 probe、trace 摘要、独立 chrF 评分入口。
- 可选 simulstream 适配、服务器配置、项目环境安装器、CPU CI 与真实模型测试入口。
- 本地 JSON 统一模型目录/运行/服务/网页配置，命令行兼容覆盖；配置相对路径固定以配置文件目录解析。
- 真实后端导入前强制离线/关闭 Hub 遥测，网页从本地端点读取公开默认值；缺失权重不触发下载。
- Docker 现有环境可用 `python3 run_s2tt.py` 或 Bash 启动脚本直接运行源码，无需安装项目命令；脚本不补装依赖。

## 服务器验收顺序

1. 使用已准备的 Python 3.12 容器环境，核对依赖和固定 2B 文件；缺环境时才使用可选安装器。执行环境自检。
2. 官方中文→英文健康检查，保存原始日志。
3. 英文完整/短前缀 probe，人工核查源转写、中文语义、否定/数字/专名。
4. 设置真实测试环境变量，执行三项 real_model 合同测试；不将格式检查当语义评测。
5. 同一录音分别运行 boundary/LA2、causal_fast/wallclock_1x，对照唯一音频RTF、排队和修订。
6. 运行真实麦克风与30分钟以上长流，检查尾段排空、缓冲、错误和资源趋势。
7. 单独换9B目录/配置/测试变量，重复前述检查。配置预算均为候选参数。

语义延迟需要独立标注的源信息到达位置，当前日志保持该项 unavailable，不从模型时间戳或中文字符数估算。观察到的声学暂停和预测 cue 覆盖是裁剪门槛，并非语义完整性的形式证明。
